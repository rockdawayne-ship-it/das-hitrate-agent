## 실제 Ollama 검사

`python scripts/verify_ollama.py` 실행: **3종 통과**.

기준은 16셀·15PCS·배송처차수·10시간이며, PRD 정답 샘플 데이터만 사용했다.

| 요청 | 검증된 계획 |
|---|---|
| 셀을 두 배로 늘리면 어떻게 돼? | 기준과 32셀·15PCS 비교 |
| 셀 수를 현재의 세 배로 바꾸고 토트는 그대로 유지하면? | 기준과 48셀·15PCS 비교 |
| 토트 용량을 지금의 두 배로 늘려서 비교해줘 | 기준과 16셀·30PCS 비교 |

요청하지 않은 날짜·검토기준 필터가 추가되지 않는지도 확인했다. 숫자 설명은 도구 결과로 생성하며 모델의 자유 생성 문장을 성과 수치로 사용하지 않는다. 위 3종 통과는 모든 자연어 표현의 정확성을 보장하지 않는다.

## 65만 행 성능 검사

`python scripts/benchmark.py` 실행. 난수 시드 17, **합성 데이터 650,000행·245일**, XLSX 크기 **17.61MB**.

| 항목 | 측정 | PRD 기준 |
|---|---:|---:|
| 파일 검사·읽기·정규화·검증·DB 저장 | 8.405초 | 90초 이내 |
| 저장 DB 로딩 포함 시나리오 1개 계산 | 1.943초 | 15초 이내 |

엑셀 샘플 생성 시간과 사용자 매핑 확인 대기 시간은 제외했다. 계산 측정 전 입력 프레임 캐시를 비워 저장 DB에서 로딩하도록 했다. AI 응답 시간은 계산 성능에 포함하지 않았다.

# 이 PC의 Ollama 설정과 검증

검증일: 2026-10-07. Core Ultra 9 275HX, RAM 64GB, RTX 5090 Laptop GPU 24GB, Ollama 0.35.1 환경.

## 적용 설정

| 항목 | 값 |
|---|---|
| 기본 모델 | `qwen3:30b-a3b` |
| 로컬 모델 ID | `ad815644918f` |
| 구조 / 양자화 | Qwen3 MoE 30.5B / Q4_K_M |
| 문맥 길이 | 8,192 토큰 |
| 최대 생성 길이 | 2,400 토큰 |
| 생각 모드 | 끔 (`think=false`) |
| temperature | 0 |
| 메모리 유지 시간 | 마지막 모델 요청 후 10분 |
| 접속 주소 | `http://127.0.0.1:11434` |

`das_agent/llm.py`에 앱 기본값을 적용했다. Windows 전체 Ollama 환경설정은 변경하지 않았다. 설치 모델은 유지하며, 앱이 질문을 해석할 때 위 설정을 요청마다 전달한다. `ollama run`으로 직접 대화하면 앱 설정과 다를 수 있다.

30B-A3B는 MoE 모델이다. 활성 파라미터 수가 작더라도 전체 모델 가중치에 필요한 메모리는 확보해야 한다. 이 PC에서는 `ollama ps`에 모델 전체가 `100% GPU`, 사용 크기 약 19GB로 표시됐다. 컨텍스트는 짧은 운영 요청에 맞춰 8K로 제한했다. 이 선택은 현재 앱의 실행 검증에 근거하며 다른 모든 Qwen 모델보다 우수하다는 비교 결과는 아니다. [공식 모델 정보](https://ollama.com/library/qwen3:30b-a3b), [Ollama GPU 적재 확인](https://docs.ollama.com/faq).

## 실제 측정

모델 적재 후 `nvidia-smi` 출력: 총 24,463MiB, 사용 18,730MiB, 남음 5,408MiB. 사용량은 다른 앱과 디스플레이가 사용하는 메모리도 포함하며 실행 상황에 따라 달라진다.

PRD 합성 정답 데이터로 모델 해석 → 계획 검증 → 계산 → 결과 설명까지 실행했다.

| 요청 | 확인한 설정 | 전체 처리 시간 | 결과 |
|---|---|---:|---|
| 셀을 두 배로 늘리면 어떻게 돼? | 32셀 / 토트 15PCS | 1.827초 | 통과 |
| 셀 수를 현재의 세 배로 바꾸고 토트는 그대로 유지하면? | 48셀 / 토트 15PCS | 1.650초 | 통과 |
| 토트 용량을 지금의 두 배로 늘려서 비교해줘 | 16셀 / 토트 30PCS | 1.339초 | 통과 |

측정값은 모델이 이미 메모리에 올라온 상태의 짧은 요청 3건이다. 최초 적재 시간, 긴 질문, 실제 대용량 출고 데이터의 처리 시간을 대표하지 않는다. API가 반환한 생성 토큰 수와 생성 시간을 나누면 약 149~150토큰/초였다.

재현: 앱 실행용 Python으로 `scripts/verify_ollama.py`를 실행한다. 모델명·검사시각·처리시간·API 계측값은 `%LOCALAPPDATA%\DAS_HitRate_Agent\ollama-verification.json`에 저장된다. 현재 검증 기록 사본은 `ollama-30b-verification.json`이다.

관련 에이전트·회귀·화면 테스트 31개가 통과했다(8.48초). 실행 중인 앱에서도 새 모델 연결을 갱신하고 합성 2,623행에 대해 토트 용량 2배 요청을 실행했다. 기준 2,098토트와 변경 후 1,889토트의 비교 결과가 표시됐다. 화면 증거는 `ollama-profile-preview.jpg`에 저장했다.

## 사용과 조정

`Start-DAS.cmd`를 실행하고 사이드바에 **로컬 AI 연결됨 · qwen3:30b-a3b**가 표시되는지 확인한다. 기존 탭에는 **모델 연결 다시 확인**을 누른다.

다른 GPU 작업으로 여유가 부족하면 설치되어 있는 `qwen3:8b`를 사용할 수 있다. 앱을 종료한 뒤 PowerShell에서 다음과 같이 실행한다. 이 환경변수는 해당 PowerShell과 그곳에서 시작한 앱에만 적용된다.

```powershell
$env:DAS_OLLAMA_MODEL = 'qwen3:8b'
.\Start-DAS.ps1
```

30B 기본값으로 돌아오려면 앱을 종료하고 해당 PowerShell의 `DAS_OLLAMA_MODEL`을 지운 뒤 다시 실행한다. 모델의 즉시 메모리 해제가 필요하면 `ollama stop qwen3:30b-a3b`를 사용한다. 다음 모델 요청 시 다시 적재한다.

계산 엔진과 모델 연결부는 분리되어 있다. 자유 대화용 외부 API의 연결 지점은 [API 확장 안내](04_API_EXTENSION.md)에 유지했다. 아직 외부 API는 연결하지 않았다. 응답 형식·생각 모드·메모리 유지 옵션은 [Ollama Chat API](https://docs.ollama.com/api/chat)에 따른다.
